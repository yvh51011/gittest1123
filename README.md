# WordNest

영어 단어를 가볍게 학습할 수 있는 웹 앱입니다.  
플래시카드, 퀴즈, 단어장 기능을 HTML / CSS / JavaScript로 구현했습니다.

## 실행 방법

1. 이 저장소를 클론하거나 다운로드합니다.
2. `index.html`을 브라우저에서 엽니다.

별도 설치나 서버 실행은 필요 없습니다.

## 기능

- **플래시카드** — 카드를 클릭해 뜻을 확인하고, 외움/모름을 기록합니다.
- **퀴즈** — 4지선다 문제로 복습합니다.
- **단어장** — 단어를 검색·추가·삭제하고 학습 상태별로 필터링합니다.
- **진행 저장** — 학습 상태와 연속 정답 수를 브라우저 `localStorage`에 저장합니다.
